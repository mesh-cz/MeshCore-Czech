# MeshCore Czech

Komunitní firmware pro repeatery sítě mesh-cz.

## Firmware ke stažení

Schválená vydání firmwaru budou zveřejňována v sekci
[Releases](https://github.com/mesh-cz/MeshCore-Czech/releases).

První vydání v tomto repozitáři se připravuje. Při stahování vždy vyberte
soubor určený pro konkrétní desku repeateru a přečtěte si pokyny k danému vydání.

## Dokumentace

Rychlý postup po nahrání, přehled změn a manuály budou doplněny společně
s příslušným vydáním firmwaru.
