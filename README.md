# MeshCore Czech

[EN — English version below](#english)

Komunitní firmware pro repeatery sítě mesh-cz.

MeshCore Czech je fork původního projektu
[MeshCore](https://github.com/meshcore-dev/MeshCore), rozšířený o funkce pro českou komunitu v České republice.

## Firmware ke stažení

Schválená vydání firmwaru budou zveřejňována v sekci
[Releases](https://github.com/mesh-cz/MeshCore-Czech/releases).

První vydání v tomto repozitáři se připravuje. Při stahování vždy vyberte
soubor určený pro konkrétní desku repeateru a přečtěte si pokyny k danému vydání.

## Dokumentace

Rychlý postup po nahrání, přehled změn a manuály budou doplněny společně
s příslušným vydáním firmwaru.

## English

Community firmware for repeaters on the mesh-cz network.

MeshCore Czech is a fork of the original
[MeshCore](https://github.com/meshcore-dev/MeshCore) project, extended with features for the Czech community in the Czech Republic.

### Firmware downloads

Approved firmware releases will be published in the
[Releases](https://github.com/mesh-cz/MeshCore-Czech/releases) section.

The first release in this repository is being prepared. When downloading,
always select the file for your specific repeater board and read the
instructions for that release.

### Documentation

A quick setup guide, changelog and manuals will be added alongside the
corresponding firmware release.
